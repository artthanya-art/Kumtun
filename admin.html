จัดการเนื้อหาเว็บไซต์

เว็บไซต์นี้เป็นเว็บสถิต (static) ไม่มีฐานข้อมูลหรือเซิร์ฟเวอร์เบื้องหลัง หน้านี้จึงเป็น "เครื่องมือช่วยสร้างไฟล์ตั้งค่า" — กรอกข้อมูลด้านล่าง แล้วดาวน์โหลดไฟล์ไปแทนที่ไฟล์เดิมใน GitHub repo เว็บไซต์จริงจะโหลดค่าที่ตั้งไว้ให้ผู้เข้าชมทุกคนเห็นเหมือนกัน

วิธีใช้งาน

  1. ถ้าเคยตั้งค่าไว้แล้ว กด "อัปโหลดไฟล์ ads-config.json เดิม" ด้านล่างเพื่อโหลดค่ามาแก้ต่อ (ข้ามได้ถ้าตั้งค่าครั้งแรก)
  2. กรอก/แก้ไขข้อมูลโฆษณาแต่ละตำแหน่ง และลิงก์ที่ต้องการแสดงในหน้าเว็บ
  3. กด "ดาวน์โหลดไฟล์ ads-config.json" ที่ด้านล่างสุดของหน้านี้
  4. ไปที่ GitHub repo ของเว็บไซต์ → เปิดไฟล์ ads-config.json → กดไอคอนดินสอ (Edit) → ลบเนื้อหาเดิมแล้ววางเนื้อหาใหม่ (หรือใช้ "Upload files" แทนที่ไฟล์เดิมได้เลย) → Commit changes
  5. รอ 1-2 นาที เว็บไซต์จะอัปเดตให้ผู้เข้าชมทุกคนเห็นค่าล่าสุดโดยอัตโนมัติ

ลิงก์ท้ายเว็บไซต์

เช่น ลิงก์สปอนเซอร์ เว็บพันธมิตร หรือแหล่งข้อมูลที่เกี่ยวข้อง จะแสดงเป็นแถวลิงก์เหนือข้อความ disclaimer ท้ายหน้าเว็บ

ไฟล์ตั้งค่าที่พร้อมใช้งาน

กดปุ่มด้านล่างเพื่อสร้างไฟล์ล่าสุดจากข้อมูลที่กรอกไว้ด้านบน

วิธีใช้งาน (มี 2 ไฟล์ต้องอัปโหลดต่อการเปลี่ยนแปลง)

  1. ถ้าเคยเพิ่มบทความไว้แล้ว กด "อัปโหลดไฟล์ articles-config.json เดิม" เพื่อโหลดมาแก้ต่อ
  2. กด "+ เพิ่มบทความ" แล้วกรอกหัวข้อ วันที่ เกริ่นนำ รูปปก และเนื้อหา — ตรวจชื่อไฟล์ (slug) ให้เรียบร้อยก่อนเผยแพร่จริง เพราะถ้าแก้ทีหลังลิงก์เดิมจะใช้ไม่ได้
  3. ไฟล์ที่ 1: กด "📄 ดาวน์โหลดไฟล์ HTML บทความนี้" ที่แต่ละบทความ (หรือ "ดาวน์โหลดทุกบทความเป็นไฟล์ HTML" เพื่อเอาทีเดียวหมด) แล้วอัปโหลดไฟล์ .html ที่ได้ไปไว้ในโฟลเดอร์ article/ ของ GitHub repo (พิมพ์ article/ชื่อไฟล์.html ตอนอัปโหลดเพื่อสร้างโฟลเดอร์อัตโนมัติถ้ายังไม่มี)
  4. ไฟล์ที่ 2: กด "ดาวน์โหลดไฟล์ articles-config.json" แล้วอัปโหลดไปแทนที่ไฟล์เดิมที่ root ของ repo (ไฟล์นี้คือรายการสรุปที่หน้ารวมบทความใช้แสดงการ์ด)
  5. รอ 1-2 นาที บทความจะขึ้นที่หน้า articles.html และเปิดอ่านแยกได้ที่ลิงก์จริง เช่น article/ชื่อไฟล์.html ให้ทุกคนเห็นอัตโนมัติ

ไฟล์ articles-config.json (รายการสรุปสำหรับหน้ารวมบทความ)

กดปุ่มด้านล่างเพื่อสร้างไฟล์ล่าสุดจากบทความที่กรอกไว้ด้านบน — ไฟล์นี้ไม่มีเนื้อหาเต็มของบทความ (อยู่ในไฟล์ HTML แยกแล้ว) จึงมีขนาดเล็กและโหลดเร็ว

หน้านี้ไม่ได้เชื่อมต่อกับเว็บไซต์จริงแบบเรียลไทม์ — การเปลี่ยนแปลงจะมีผลก็ต่อเมื่อคุณดาวน์โหลดไฟล์และอัปโหลดไปแทนที่ใน GitHub repo เท่านั้น ข้อมูลที่กรอกในหน้านี้จะหายไปเมื่อปิดหน้าต่าง (ยังไม่ได้บันทึกอัตโนมัติ) แนะนำให้ดาวน์โหลดไฟล์เก็บไว้ทุกครั้งที่แก้ไขเสร็จ
