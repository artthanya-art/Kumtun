# คุ้มทุน — เครื่องคำนวณ ROI การลงทุนประหยัดพลังงาน

เว็บคำนวณความคุ้มค่าการลงทุนอุปกรณ์ประหยัดพลังงานและทรัพยากร รองรับ 8 ประเภท:
โซลาร์เซลล์ (พร้อมแบตเตอรี่/มิเตอร์ TOU), รถยนต์ไฟฟ้า (BEV), รถยนต์ไฮบริด (HEV/PHEV),
เครื่องใช้ไฟฟ้าอื่นๆ, ไฟ LED, ฉนวนกันความร้อน, เครื่องกรองน้ำ, ระบบรีไซเคิลน้ำ (RO/UF)

คำนวณ: คืนทุนแบบธรรมดา/คิดลด, NPV, IRR, ROI, CO2/ปริมาณน้ำที่ลดได้ และสร้างรายงาน PDF ได้ในตัว

## โครงสร้างไฟล์
เว็บนี้แยกไฟล์ออกเป็นหลายส่วน เพื่อให้ใส่ Google Analytics หรือโค้ดติดตามอื่นๆ ได้โดยไม่ต้องกังวลว่าจะหายไปเมื่ออัปเดตเว็บ:

- **`index.html`** — เชลล์หลัก (เสถียร ไม่ต้องอัปเดตอีกหลังจากตั้งค่าครั้งแรก) ใส่ Google Analytics ที่ไฟล์นี้ได้เลย มีคอมเมนต์กำกับตำแหน่งไว้ให้แล้ว
- **`app.js`** — เนื้อหาหน้าเว็บทั้งหมด (HTML) รวมกับตรรกะการคำนวณ (JavaScript) — ไฟล์นี้จะถูกอัปเดตเมื่อมีการแก้ไข/เพิ่มฟีเจอร์
- **`style.css`** — สไตล์ทั้งหมด — อัปเดตเมื่อมีการปรับหน้าตา
- **`admin.html`** — หน้าหลังบ้าน จัดการโฆษณา/ลิงก์/บทความ (มีรหัสผ่านป้องกัน)
- **`ads-config.json`** — ไฟล์ตั้งค่าโฆษณาและลิงก์ (สร้าง/แก้ไขผ่าน admin.html)
- **`articles.html`** — หน้ารวมบทความ + หน้าอ่านบทความ (ลิงก์แบบ `articles.html#article-id`)
- **`articles-config.json`** — ไฟล์เก็บเนื้อหาบทความทั้งหมด (สร้าง/แก้ไขผ่าน admin.html)

**เมื่ออัปเดตเว็บครั้งต่อไป:** อัปโหลดแค่ `app.js` และ/หรือ `style.css` ไปแทนที่ไฟล์เดิม **ไม่ต้องอัปโหลด `index.html` ซ้ำอีก** โค้ด Google Analytics ที่ใส่ไว้จะไม่หายไป

## วิธีใช้งาน
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม (ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์และไลบรารีกราฟ)

## เผยแพร่เป็นเว็บไซต์
โปรเจกต์นี้ตั้งค่าให้พร้อมใช้กับ **GitHub Pages** แล้ว — แค่เปิด Settings → Pages ของ repo นี้
แล้วเลือก branch `main` โฟลเดอร์ `/ (root)` ก็จะได้ลิงก์เว็บทันที

## จัดการโฆษณา ลิงก์ และบทความ (admin.html)
เว็บไซต์นี้เป็นเว็บสถิต (static) ไม่มีฐานข้อมูล/เซิร์ฟเวอร์เบื้องหลัง ระบบจัดการเนื้อหาจึงทำงานผ่านไฟล์ตั้งค่า
(`ads-config.json`, `articles-config.json`) ที่หน้าเว็บหลักจะอ่านค่าไปแสดงให้ผู้เข้าชมทุกคนเห็นเหมือนกัน

**วิธีแก้ไขโฆษณา/ลิงก์:**
1. เปิด `admin.html` — ต้องกรอกรหัสผ่านก่อนเข้าใช้งาน (ค่าเริ่มต้นคือ `kuntun2026`)
2. เลือกแท็บ "โฆษณาและลิงก์" กรอกข้อมูลโฆษณาแต่ละตำแหน่ง (รองรับ Google AdSense, แบนเนอร์รูปภาพ+ลิงก์, หรือโค้ด HTML กำหนดเอง) และลิงก์ท้ายเว็บไซต์
3. กด "ดาวน์โหลดไฟล์ ads-config.json"
4. อัปโหลดไฟล์ไปแทนที่ไฟล์เดิมชื่อเดียวกันใน repo นี้ (Add file → Upload files) แล้ว Commit
5. รอ 1-2 นาที เว็บไซต์จะอัปเดตให้ทุกคนเห็นค่าล่าสุดอัตโนมัติ

**วิธีเพิ่ม/แก้ไขบทความ (สร้างไฟล์ HTML จริงต่อบทความ เพื่อให้ Google อ่านเจอ):**
1. เปิด `admin.html` → เลือกแท็บ "บทความ"
2. กด "+ เพิ่มบทความ" กรอกหัวข้อ วันที่ เกริ่นนำ รูปปก (ถ้ามี) และเนื้อหา — เขียนเป็นข้อความธรรมดาได้เลย (เว้นบรรทัดว่างระหว่างย่อหน้า) หรือใส่ HTML เอง เช่น `<h2>`, `<ul><li>`, `<img>` เพื่อจัดรูปแบบเพิ่มเติม
3. ตรวจ "ชื่อไฟล์ (slug)" ให้เรียบร้อยก่อนเผยแพร่จริง — ถ้าแก้ทีหลังลิงก์เดิมจะใช้ไม่ได้ (กดปุ่ม 🔄 ให้สร้างจากหัวข้อให้อัตโนมัติได้)
4. **ไฟล์ที่ 1:** กด "📄 ดาวน์โหลดไฟล์ HTML บทความนี้" (หรือ "ดาวน์โหลดทุกบทความเป็นไฟล์ HTML" เอาทีเดียวหมด) แล้วอัปโหลดไฟล์ `.html` ไปไว้ในโฟลเดอร์ `article/` ของ repo (พิมพ์ `article/ชื่อไฟล์.html` ตอนอัปโหลดผ่าน GitHub เพื่อสร้างโฟลเดอร์อัตโนมัติถ้ายังไม่มี)
5. **ไฟล์ที่ 2:** กด "ดาวน์โหลดไฟล์ articles-config.json" แล้วอัปโหลดไปแทนที่ไฟล์เดิมที่ root ของ repo (ไฟล์นี้คือรายการสรุปที่หน้ารวมบทความใช้แสดงการ์ด — ยังเก็บเนื้อหาเต็มไว้ด้วยเผื่อกลับมาแก้ไขทีหลัง)
6. บทความจะปรากฏที่หน้า `articles.html` และเปิดอ่านแยกได้ที่ลิงก์จริง เช่น `article/ชื่อไฟล์.html` — Google และบอทแชร์ลิงก์ (LINE/Facebook) อ่านเนื้อหาได้ทันทีโดยไม่ต้องรอ JavaScript
7. ถ้าเคยเพิ่มบทความไว้แล้วและอยากแก้ต่อ กด "อัปโหลดไฟล์ articles-config.json เดิม" ในแท็บบทความก่อนแก้ไข

**ทำไมต้องมี 2 ไฟล์ต่อบทความ:** ไฟล์ HTML แต่ละไฟล์มี title/meta description/Open Graph/JSON-LD ของบทความนั้นโดยเฉพาะ ทำให้ Google และแอปแชร์ลิงก์อ่านเนื้อหาได้จริง (ต่างจากระบบเดิมที่โหลดเนื้อหาด้วย JavaScript ซึ่งบอทบางตัวอ่านไม่เจอ) ส่วน `articles-config.json` ใช้แค่แสดงการ์ดในหน้ารวมเท่านั้น

**เปลี่ยนรหัสผ่านหน้า admin:** เปิดไฟล์ `admin.html` หาบรรทัด `ADMIN_PASSWORD_HASH` แล้วแทนที่ด้วย SHA-256 hash
ของรหัสผ่านใหม่ (ให้ Claude ช่วยคำนวณ hash ให้ได้ ถ้าไม่สะดวกคำนวณเอง) — **หมายเหตุ:** การป้องกันนี้เป็นแค่ตัวกันคน
ทั่วไปเปิดเจอโดยบังเอิญเท่านั้น ไม่ใช่ระบบความปลอดภัยจริงจัง เพราะเป็นเว็บสถิตไม่มีเซิร์ฟเวอร์ตรวจสอบสิทธิ์

ตำแหน่งโฆษณามี 3 จุด: บนสุด (เหนือแท็บเลือกอุปกรณ์), กลางเนื้อหา (หลังผลลัพธ์), และท้ายเว็บไซต์ —
ถ้าไม่ตั้งค่า (`"type": "none"`) กล่องโฆษณาจะไม่แสดงเลย ไม่ต้องกังวลว่าจะมีกล่องว่างค้างอยู่
