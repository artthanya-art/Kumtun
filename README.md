# คุ้มทุน — เครื่องคำนวณ ROI การลงทุนประหยัดพลังงาน

เว็บคำนวณความคุ้มค่าการลงทุนอุปกรณ์ประหยัดพลังงานและทรัพยากร รองรับ 7 ประเภท:
โซลาร์เซลล์ (พร้อมแบตเตอรี่/มิเตอร์ TOU), รถยนต์ไฟฟ้า (BEV), รถยนต์ไฮบริด (HEV/PHEV),
เครื่องใช้ไฟฟ้าอื่นๆ, ไฟ LED, ฉนวนกันความร้อน, เครื่องกรองน้ำ

คำนวณ: คืนทุนแบบธรรมดา/คิดลด, NPV, IRR, ROI, CO2 ที่ลดได้ และสร้างรายงาน PDF ได้ในตัว

## วิธีใช้งาน
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม (ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์และไลบรารีกราฟ)

## เผยแพร่เป็นเว็บไซต์
โปรเจกต์นี้ตั้งค่าให้พร้อมใช้กับ **GitHub Pages** แล้ว — แค่เปิด Settings → Pages ของ repo นี้
แล้วเลือก branch `main` โฟลเดอร์ `/ (root)` ก็จะได้ลิงก์เว็บทันที

## จัดการโฆษณาและลิงก์ (admin.html)
เว็บไซต์นี้เป็นเว็บสถิต (static) ไม่มีฐานข้อมูล/เซิร์ฟเวอร์เบื้องหลัง ระบบจัดการโฆษณาจึงทำงานผ่านไฟล์ตั้งค่า
`ads-config.json` ที่หน้าเว็บหลักจะอ่านค่าไปแสดงให้ผู้เข้าชมทุกคนเห็นเหมือนกัน

**วิธีแก้ไขโฆษณา/ลิงก์:**
1. เปิด `admin.html` (เช่น `ชื่อเว็บไซต์คุณ/admin.html`)
2. กรอกข้อมูลโฆษณาแต่ละตำแหน่ง (รองรับ Google AdSense, แบนเนอร์รูปภาพ+ลิงก์, หรือโค้ด HTML กำหนดเอง) และลิงก์ท้ายเว็บไซต์
3. กด "ดาวน์โหลดไฟล์ ads-config.json"
4. อัปโหลดไฟล์ไปแทนที่ไฟล์เดิมชื่อเดียวกันใน repo นี้ (Add file → Upload files) แล้ว Commit
5. รอ 1-2 นาที เว็บไซต์จะอัปเดตให้ทุกคนเห็นค่าล่าสุดอัตโนมัติ

ตำแหน่งโฆษณามี 3 จุด: บนสุด (หลังแท็บเลือกอุปกรณ์), กลางเนื้อหา (หลังผลลัพธ์), และท้ายเว็บไซต์ —
ถ้าไม่ตั้งค่า (`"type": "none"`) กล่องโฆษณาจะไม่แสดงเลย ไม่ต้องกังวลว่าจะมีกล่องว่างค้างอยู่

## ข้อจำกัด
ตัวเลขทั้งหมดเป็นการประมาณการเพื่อประกอบการตัดสินใจเบื้องต้นเท่านั้น ไม่ใช่คำแนะนำทางการเงินหรือการลงทุน
